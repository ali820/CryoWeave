# 架构说明

## Monorepo，而不是巨型插件

每个 `plugins/<name>` 都是独立 DSH Bundle，可以单独安装。仓库统一的是开发规范、共享数据结构和验证流程，不是强制所有插件同时启用。

## 当前分层

```text
研究者和项目权威文件
        ↓
DSH Agent：理解任务、组织流程、解释异常
        ↓
Host 插件：受限工具、参数校验、任务生命周期
        ↓
独立 Python worker：确定性文件/GEE/统计操作
        ↓
结构化结果：findings、manifest、QA、图表和证据
```

`research-evidence` 是只读 Host 插件，不执行研究项目脚本、不修改研究文件、不访问网络。其他插件可以复用它的 finding 和证据模型，但不要求彼此安装。

## 共享与专用的边界

共享：运行清单、证据状态、finding 结构、文件安全、测试约定。

专用：遥感算法、统计模型、物理求解器、项目阈值和科学解释。项目预设必须可审阅，不能硬编码成普遍规则。

# 插件开发规范

## 每个插件的最低内容

- `package.json`：Bundle 声明、运行入口、导出资源；
- `cordis.patch.yml`：插件行和受限配置；
- `index.js`：Host 工具注册与进程生命周期；
- `README.md`：用途、参数、示例、限制和验证；
- `locale/en.json`、`locale/zh.json`、`icon.svg`；
- 自测与真实只读验证记录。

## 安全与可复现

1. 文件工具只允许配置的项目根目录，拒绝路径逃逸和符号链接逃逸。
2. 默认只读，不修改原研究文件，不执行任意模型代码。
3. 网络、导出和任务提交必须与只读检查分开。
4. 不读取或输出凭据，不把密钥写入配置或会话。
5. 大规模扫描必须限制文件数、文本大小、哈希大小、结果数和执行时间。
6. 结构化校验不等于科学真实性；AI 只辅助定位和解释冲突。

## 完成定义

语法检查、离线自测、真实项目只读验证、元数据检查、安装状态检查全部完成。安装成功不等于当前 Host 已激活，必须分别报告。
